# Contributing

Thanks for your interest in contributing!

- Fork the repo and create a branch for your change: `git checkout -b feature/my-change`
- Write tests for your change where applicable
- Run the tests and lint locally
- Open a Pull Request with a clear description

## Code style
- Use consistent indentation (2 spaces)
- Add tests for bugs and new features

## Reporting issues
- Please open an issue and provide steps to reproduce, expected vs actual behavior, and relevant logs.
